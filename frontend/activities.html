Capstone Project Program

Internship | Learn by Doing

The Capstone Project Program helps students build real-world, portfolio-ready projects using real data, real problems, and real impact.

The program focuses on Data, Database, Operations Research, and Linear Algebra, covering data collection, preprocessing, SQL querying, optimization models, linear programming, matrix operations, and applications in machine learning.

Students work through problem identification, data and model development, analysis and optimization, results reporting, and a final capstone deliverable.

Tools and technologies include Python, MySQL, Excel, PuLP, and NumPy. The session is guided by Dr. Bhargav Revankar, Professor and HoD MCA.

Hacklite 2.0

Competition | Hackathon

Hacklite 2.0 successfully brought together innovation, collaboration, and technical excellence.

The hackathon witnessed participation from 10 teams across 5 clubs, each working on selected problem statements to develop fully functional web applications, including deployment.

A unique aspect of the event was the remote development phase, where teams collaborated virtually, demonstrating strong coordination, communication, and adaptability.

The final presentations reflected impressive problem-solving approaches, creativity, and practical implementation skills.
